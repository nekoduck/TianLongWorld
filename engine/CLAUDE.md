# engine/
> L2 | 父级: /CLAUDE.md

TLBB-Engine：DDD + CQRS + 事件溯源 + Graph RAG 的武侠沙盒引擎，与 backend/（MVP 状态树导演）并列的下一代后端。
业务代码全部位于 app/ 包内，cwd 须为 engine/（`app.main:app`、`python -m app.seed` 与 pytest 的 pythonpath 均以此为根）。
世界本体只能由 data/source_text 的原著经播种管道产出，定格在时间锚点 T=0（原著开篇、段誉刚离家出走之时）；事件流是唯一真相，Neo4j 图谱与 Qdrant 记忆都只是它的投影。
大模型五职责皆无写端口：抽取原著、解析意图、地下城主推演（属性变化、叙事时钟、微观事实、路由；只在自由文本回合，点选回合由气运确定性取值，不花钱；NPC 撞见与狭路相逢的判官也是它，每回合至多一场）、宏观议程（为有执念的核心 NPC 立议程，只在初临江湖 / 新的一日 / 江湖震动时一轮）、渲染文本（同一次调用从可供性目录挑招配风味）——一切提议都经领域闸门定案（语义物理引擎：量级、时钟坍缩、等价交换；议程过 npc.admit，风味过 options.compose）。
花钱的边界：抽取原著、图谱自愈、T=0 审计、掌故与地理注记由 Claude 子代理经 export / ingest 完成，绝不调用付费大模型（抽取与自愈须显式 --use-llm 才会调用，audit / lore / geo 没有 --use-llm）；付费大模型只服务运行期四职责（意图 / 地下城主 / 议程 / 叙事），且有每进程的调用次数保险丝 LLM_CALL_LIMIT。
