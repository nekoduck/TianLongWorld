# persistence/
> L2 | 父级: engine/app/infrastructure/CLAUDE.md

持久化适配：每个端口一份生产实现 + 一份内存实现，两份共跑同一套契约测试（tests/test_event_store.py、tests/test_world_graph.py / test_world_graph_heartbeat.py / test_world_graph_spatial.py）。
事件账本是真相；图谱与向量记忆是投影——它们可以丢、可以落后、可以整体重建，事件流不行。

成员清单
memory_event_store.py: InMemoryEventStore，进程内字典 + asyncio 锁；原子追加、乐观并发、版本从 1 连续；事件经 JSON 往返（decode_event，与生产实现同一个读出入口）后入账，与 JSONB 实现同样拒收不可序列化的事件
postgres_event_store.py: PostgresEventStore（asyncpg 连接池），domain_events 表以 JSONB 存事件、(stream_id, version) 唯一、event_id 唯一；触发器拒绝 UPDATE / DELETE / TRUNCATE（历史在数据库层面不可篡改）；读出一律经 decode_event，库里的旧词汇被上抛为现行事件而字节不动；追加走流级咨询锁 → 事务内核对版本 → unnest 批量插入，唯一约束兜底映射为 ConcurrencyError；建表用全局咨询锁串行化
memory_graph.py: InMemoryWorldGraph（WorldReader + WorldProjector + WorldSeeder），正典是蓝图索引，覆盖层直接复用领域的 evolve 折叠出 PlayerState（投影与聚合根同构，熟练度 / 悟性 / 气血原样进快照）；快照只取所在地、在场的健在者（带称号；后来才到场的 arrives_with 者不在场）、持有者落在本地 / 在场者 / 玩家身上的物品（下落不明者没有持有者、arrives_with 之物与 PlayerState.consumed 用掉之物都不进任何快照）、玩家所会 ∪ 在场者所会 ∪ 行囊典籍（获取要求所载）可得的武学；P1 视图：羁绊带 era 与 lead（source 一方为上首）、人物带外显人设 PersonaView、物品带 portable / hazard / use、出口的 hostile_ahead（去处在场者里有对玩家敌视且未被制住的人）、facts 收知情人之一在场的见闻 ∪ PlayerState.known_facts 里主体或 unlock 目标在场（此地、在场者、可见之物）的见闻（known 标明已知，主体与知情人去重保序、与 MERGE 同口径），labels 把 fact:<slug> 映射为见闻正文、swm:<名> 映射为人群名；语义物理引擎的 clocks / emerged 同由 evolve 折叠：时钟挂在此地、在场者、可见之物或玩家自己身上才进快照，微观事实（PlayerState.emerged，至多 EMERGED_MAX 条、重提即刷新）的主体与 {此地, 在场者, 可见之物} 有交集才进快照；世界心跳同由 evolve 折叠（tick / activities / traces / tokens：TimePassed 按 ambient.elapse 先剪到期的痕迹、再剪已结束且痕迹不在的活动，ItemDecayed 折进 consumed、ItemPilfered 只改持有者）：快照的 tick 即 PlayerState.tick，activities 取此地的活动（ActivityView.state 按 tick 现算），traces 取此地 remaining(tick) ≥ 1 的痕迹，swarms 取蓝图里落在此地的人群（routed = 有一个参与者含它、此刻进行中的溃散逃离活动），rumors 取 reached 含此地的消息——全局的事件流不进快照；空间属性图与探索迷雾：出路取 geography.ways（方位 / 交通方式 / 耗时，一对 (from, to) 一条），discovery 经 geography.discovery 按 PlayerState.visited / heard 与蓝图 sights 的地标 / 名胜现算；分层 NPC 生态：人物此世所在 = PlayerState.npc_at 否则正典所在（在场者、出口 hostile_ahead、物品持有者与见闻知情人都按它算），CharacterView.wounded = npc.wounded（npc_wounds > tick）；议程与中断只在聚合里、不进快照
