# domain/
> L2 | 父级: engine/app/CLAUDE.md

领域层：世界是什么（本体与掌故）、路怎么走（空间属性图：方位、交通方式、耗时，与玩家认得哪些去处的探索迷雾）、发生过什么（事件）、此刻怎样（聚合根折叠，含悬着的叙事时钟、此世的活动、痕迹、消息与 NPC 的议程和所在）、能做什么（裁决规则）、花多少时间（命令耗时）、时间走过之后世界怎样（世界物理：余波、扩散、生态；NPC 寻路行军与相撞的裁决）、推演算不算数（语义物理闸门）、要什么样的存储（端口）。
纯 Python + Pydantic，不做 IO、不调大模型、不看时钟；唯一的外部依赖是共享内核 app/errors.py。

成员清单
models.py: 世界本体——实体 id 自带种类前缀（loc / chr / art / itm / ply / swm 人群）；Tier 是只比高下的有序等级；Attitude 是五档人情阶梯（敌视 −2 / 戒备 −1 / 漠然 0 / 友善 +1 / 信赖 +2，rank 比高下、step 按档移动并钳在两端，原有三值字面不动）；Era 关系结于何时（开篇 / 将至 / 后文）；Location（出入口映射 exits；sheltered 有遮蔽的室内由处所名末字推出——厅室屋房穴洞窟观堂阁殿店铺庙寺庵舍轩斋馆厢楼）；Character 三名分立：true_name 本名即主键（id 恒为 chr:{本名}，蓝图闸门拒收以称号篡位的主键）、titles 江湖称号、aliases 化名旧称，name / names 是派生属性，foreshadow 是从描述拆出的后文剧情（只供离线审阅，绝不进任何提示词），arrives_with 非空者后来才到场、T=0 不在任何场景；MartialArt 两道门：Acquisition 获取要求（师传 / 自悟、典籍、得门径之地、sealed 失传封存）与 Practice 修炼要求（作根基的武学、最低境界、相冲武学）；Item 至多一位物主、至多一个所在，两者皆空即下落不明（lost，孤儿，待播种期自愈），provenance 标明安放出自原著还是推断，portable 可否携带、hazard 险性（取到手即受伤）、use 用法 ItemUse（effect 疗伤 / 解毒 = Remedy、potency 1~3）、arrives_with，material 物料与 ownership T=0 的归属是派生属性；日常生态的两把尺：Material 物料（金铁 / 玉石 / 竹木 / 皮革 / 布帛 / 纸帛 / 药石 / 草木 / 饮食 / 活物 / 杂物，weathers_in 露天几日朽坏：饮食 2、纸帛 3、药石 10、布帛 15、竹木与皮革 60，其余经得起风雨）与 MATERIAL_OF_KIND（种类 → 物料的封闭表，表外即杂物）、Ownership 归属（随身 / 他持 / 遗落 / 无主）与 ownership(物主, 持有者)——sheltered / material / ownership 都不另存，蓝图与掌故的指纹因此不动；CharacterRelation 带 era（审计前一律开篇）；WorldBlueprint 是播种中间表示与最后闸门（重复 id、悬空引用、根基成环、主键不是本名、关系边自环或一对人物两条边、掌故或地理注记不自洽一律拒收），另载 personas / facts / swarms 掌故与 passages / sights 地理注记（geography.py），prerequisite_cycle 三色 DFS 供组装器复用
lore.py: 掌故本体——Persona 外显人设（character_id、likes / dislikes 每条 ≤16 字、worry 心事、sources 出处 ev:<块> / chunk:<块> 至少一条）、FactUnlock（TEACHING / LEVERAGE / HAZARD / MOTIVE + target_id）、Fact 见闻（id 形如 fact:<slug>、text ≤40 字、subject_ids、knower_ids 至少一人、unlock、sources）、SwarmNode 人群（原著写了在场却没给名姓、成群出现的人：id = swm:{name}、name ≤12、location_id、size 3~500、panic_threshold 惊惧阈值 1~10、routine 平日所为 ≤12、faction 可空、sources ≥1；不能攀谈交手、不进人情，只目睹、传话、受惊溃散——溃散与否是平行世界的事，由快照现算）；lore_integrity_errors(bp) 是掌故的蓝图闸门：悬空引用、重复的人设与见闻、知情人须是主体本人 / 同门（同一门派）/ 与主体有关系边（物品的"本人"是物主与同处一地者，武学是身负者，地点是身在其中者）、unlock 须落在蓝图的一条边上（TEACHING ↔ 主体之一 KNOWS_SKILL、LEVERAGE ↔ target 与另一主体有 HAS_RELATION、HAZARD ↔ 带 hazard 的物品、MOTIVE ↔ 有人设者）、主体与知情人不得重复（两套图谱才同构）；人群另守 id 不重复、id 即 swm:{名称}、地点须在蓝图里、门派须是蓝图里有人的门派；关系边只认开篇的（将至、后文的关系 T=0 还不存在），后来才到场的物品（arrives_with）不作主体、不作险物目标；"不得照抄原文"需要原著全文，由离线 ingest 闸门守
geography.py: 空间属性图与探索迷雾的本体——Direction 方位（东 / 南 / 西 / 北 / 东北 / 东南 / 西北 / 西南 / 上 / 下 / 内部 / 外部 / 不明，.opposite 两两互逆、不明自反）与 COMPASS 导航次序（东南西北居前、不明殿后）、TravelMethod 交通方式（步行 / 骑马 / 乘船 / 攀援 / 轻功 / 坠落——坠落只给失足坠崖类的单程出口）、DiscoveryStatus 玩家对去处的认知（亲历 / 问路 / 远眺 / 名胜 / 未知，.known 只有未知为假）与 UNKNOWN_PLACE「未知区域」；掌故式的正典注记 Passage（from_id / to_id 须是蓝图出口、direction、travel_method、time_cost 1~672 刻、basis ≤40、sources ≥1）与 Sight（location_id、landmark 地标——相邻之处远远望得见、renowned 名胜——天下皆知、sources），即 WorldBlueprint.passages / sights，由 Claude 子代理撰写、经 infrastructure/geo_gate 入库，provenance 恒为推断；Way 与 ways(bp)（每条出口一条有效属性：撰写的注记优先且 authored，否则 derive_direction（处所嵌套 → 内部 / 外部优先；再看出口标签——先抹掉去处自己的名字（「往无量山·西北角山坡」的西北是地名的一部分），四隅先于正向、正向取最先出现的一个，入进 → 内部、出 → 外部、上下；都不是即不明）/ derive_method（坠先于船，船舟渡 → 乘船、攀爬 → 攀援，其余步行）/ derive_cost（同一处所 1、否则 4）推出；缺省推导与回程对齐，往返方位永远相反：回程撰写过注记即取其反方位、耗时也随回程（回程是坠落时耗时不随：跳下去快，爬上来慢），自己推不出而回程推得出取回程之反，两头都推得出却不相反以 (from, to) 较小的一头为准）——两套图谱、Cypher 编译与 Atlas 寻路都只用这一个函数；discovery(loc, visited=, heard=, landmarks=, renowned=) 按 亲历 > 问路 > 远眺 > 名胜 定认知，都不是即未知；geography_errors(bp) 是地理注记的蓝图闸门（道路注记须落在已有出口上、不写不明、不重复、往返方位相反；可见性注记须落在已有地点、至少一项为真、不重复）；迷雾是玩家的认知而不是世界的属性——未知去处只露「未知区域」，出口标签常带地名，同样不得露给玩家与大模型
progression.py: 渐进式状态的三把尺——Mastery 火候（熟练度 × 悟性系数 → 初窥门径 / 略有小成 / 融会贯通 / 炉火纯青 / 登峰造极，effective_tier 火候不到境界打折，FOUNDATION 作根基须略有小成）、Guidance 修习方式与 GAIN 每次所得、aptitude_for 根骨天定的悟性；Vitality 伤势（MAX_HP 气血、vitality 分档、REST_GAIN 调息所得）；内部整数、对外语义，事件只记"练了多少"，"练到哪一步"永远现算；火候封顶（初窥门径最高三流、略有小成最高二流、融会贯通最高一流），gain() 让一次修习所得随武学境界折算（三流 ×1、二流 ÷1.5、一流 ÷2、绝顶 ÷3）——实测捡到绝顶秘籍读两回就成一流高手，此后要练十来回；Renown 名望六档（声名狼藉 ≤−30 / 略有恶名 ≤−10 / 籍籍无名 / 小有名气 ≥10 / 名动一方 ≥30 / 威震江湖 ≥60）与 renown(points)
combat.py: 模糊裁决的硬轨——CombatOutcome（得手 / 相持 / 轻伤 / 重伤 / 毙命）与 HP_BANDS 气血区间；assess 依境界差、性情、伤势圈出可裁区间 Stakes（admissible + canonical，境界差 + 伤势加码 ≥ 3 且对方狠辣才算极端找死，毙命才入区间；seize_id 夺物得手即易手之物，target_id 与另两路同口径）；settle 把地下城主的 CombatProposal 钳进区间与气血带（出界取确定性裁决、非毙命至少留一口气），CombatRuling.adopted 标明速写是否作废
intent.py: 命令语言 ActionType（MOVE / OBSERVE / THINK / TALK / ATTACK / TAKE / GIVE / LEARN / REST / USE / INVALID）、Approach 手段（寻常 / 武力 / 言辞 / 人情 / 计谋 / 潜行 / 借势）、Aim 所图（制人 / 夺物 / 脱身 / 求艺 / 打探 / 结交 / 化解 / 讨要 / 示警）与 PlayerIntent（action_type / target_entity / item_used / skill_used / narrative_style / reason / approach 缺省寻常 / aim / topic 话题 / motivation 此行所为 ≤24 字）；LEARN 一个动作涵盖入门与精进，USE 是服药敷药，THINK 是沉思（回想、盘算，不动手也不开口，只花时间）；motivation 随 Moved 入账，跨进新地方时与眼前所见对照（短期记忆）；指称、话题与此行所为超长或空串时规整而非拒收；(动作, 手段) 的兼容表与所图推断在 approach.py，每个动作花多少时间在 commands.py；放在 domain 而非 application，因为裁决规则消费它，领域不得反向依赖应用层；枚举与模型一律不写 docstring（只写 # 注释）——model_json_schema 就是意图解析发给大模型的 schema，只许有形状
approach.py: 「招」的词汇——Route（战 / 交 / 暗 / 定）、Row（兼容表的行，TAKE 分地上之物与他人之物）、Cell（路线 + 隐含所图 + 说法 + 师父不肯时的退路）、MOVES 封闭兼容表（逐格照搬 PROPOSAL_v2 §3.3；THINK 一行是之后添的：只有寻常 → 定）、AIMS 各动作配得上的所图、normalize（表外手段退回寻常、所图不配置空、话题落不了地置空；取他人之物以格子写明的所图为准（言辞说「夺」照样是讨要）；威逼图不来 UNCOERCIBLE 结交 / 化解 / 求艺，一律改为打探；幂等；物在谁手与话题能否落地由 rules 判定后作参数交进来）、infer_aim（说了的照说 → 格内隐含 → 威逼或带话题打探 → 敌视戒备化解 → 结交）；TacticalAxis 战术维度（ESCALATE 激化 / TRICKERY 诡道 / PACIFY 化解 / OBSERVE 旁观，值即英文键、.label 中文）与 axis_of(intent) 封闭表——出手恒激化（计谋出手也是）；打探恒旁观：所图打探、带话题的寻常攀谈、言辞带话题而不写所图（规则推断为打探，与 infer_aim 一致）；其余先看手段（武力激化、计谋 / 潜行 / 借势诡道、言辞 / 人情化解，故威逼打探激化、套话诡道、人情打探化解）、再看动作（寻常的攀谈与赠物化解；拾物、修习、移动、静观、沉思、服药、调息、天道旁观）；轴只看动作 / 手段 / 所图 / 话题，不看措辞与指称——它是选项的骨架，叙事大模型只在引擎给定的招里挑、配风味
commands.py: 命令与时间（时间是第一物理量：没有不花时间的命令——精神时光屋之治）——刻度 TICKS_PER_DAY=96（一刻十五分钟）/ TICKS_PER_SHICHEN=8 / SPAWN_TICK=32（投胎于第一日辰正）、TIME_COSTS 封闭耗时表（MOVE 4——半个时辰的脚程，只是没写道路注记时的缺省；OBSERVE / THINK / TALK / ATTACK / TAKE / GIVE / USE 1、LEARN / REST 8、INVALID 1）与 NEARBY_MOVE（同一处所之内走动 1）/ REFUSED_COST（驳回 1：试过、没成，也花了时间）/ MAX_TIME_COST（7×96，远行至多七日）、Command（意图 + 必填的 time_cost ∈ [1, 672]）、time_cost(动作, approved, here, there, way_cost)（MOVE 以那条出路的耗时 way_cost——快照 ExitView.time_cost，道路注记或 geography 推出——为准并钳在 [1, 672]，没给才看去处是否同一处所）、same_place（「上级·处所」的上级相同）、day_of（第几日，从 0 起）/ time_label（「第一日·辰正」「第二日·子初三刻」：时辰从前一日的子初起算，分初、正各四刻）/ daylight（卯至酉为昼）；耗时与措辞无关，由 rules.command 按裁决结果查表，application/world_clock 把它绑定成心跳
outcomes.py: 另两路结局词汇（与 combat.CombatOutcome 并列，都由对玩家最有利到最不利）——SocialOutcome 交涉（如愿 / 松动 / 无果 / 碰壁 / 翻脸）、CovertOutcome 暗中行事（按后果由轻到重：无痕 / 未遂 / 败露 / 失手）；单独成模块以断环：events 用它们，social / covert 又从 events 导入
social.py: 交涉硬轨（与 combat 对称）——SocialStakes（npc、所图、手段、交情、性情、分数、admissible / canonical、所求之物 subject_id、筹码 leverage_ids、求艺所需人情 need）、assess_social（交情 rank（威逼改看境界差，被制住 +2）+ 性情 + 筹码 − 难度 − 纠缠 − 虚张声势 → 五档区间；硬约束剔格：够不着无如愿、只有武力 / 计谋 / 借势会激人翻脸、仁厚不翻脸）、settle_social（出界取确定性裁决）、effects（定案 → Parleyed（带所图的标的 subject_id）+ FactLearned / ItemTransferred / RelationChanged：阶梯每次至多一档、交涉止于友善 CAP、威逼得逞畏而不服、翻脸直落敌视、求艺从不传功、永不伤人）
covert.py: 暗中取物硬轨——CovertStakes（失主、物、手段、失主态度、差额 margin、admissible / canonical）、assess_covert（境界差；失主敌视或戒备 −1、骗取信你之人 +1、失主被制住 +2；按无痕 / 未遂 / 败露 / 失手连续切片，差两境以上只有失手——东西绝不到手，暗取不是越级的后门）、settle_covert、effects（Maneuvered 恒入账；无痕易手、败露易手且失主敌视、失手只结仇；永不伤人）
stakes.py: 统一赌注门面——AnyStakes（combat.Stakes | SocialStakes | CovertStakes，同口径 admissible / canonical / contested / target_id）、Outcome、Proposal（通用提议：结局 + 扣减）、Ruling、settle_any（分派三路 settle，出界取确定性裁决；CombatProposal 照收）、route_of、Risk（稳妥 / 有险 / 凶险）与 risk_of（只看区间最坏的一端；无赌注即稳妥）

依赖说明
- rules/ 只在类型标注里引用 aggregates.PlayerState（TYPE_CHECKING），aggregates 运行期导入 rules 门面：两者互引而不成环
- models 运行期导入 lore（Persona / Fact / SwarmNode 是蓝图字段），lore 只在类型标注与闸门函数体里（调用时，取 Era）引用 models：不成环；outcomes 位于 events 之下，social / covert 由此导入而不成环
- approach 只认意图与人情、不读快照（rules 依赖它，反之不然）；social / covert 只吃纯数值输入，从快照取事实是 rules/parley 的事；reputation 读快照，只在类型标注里引用 PlayerState
- 裁决只看两样东西：快照（他人与地理的物理事实）与玩家状态（自身的逻辑事实）；回合编排保证二者版本一致后才调用
- 依赖方向：lore ← models ← progression ← combat；intent 与 outcomes 自立；models / combat / intent / outcomes ← events；models / lore / progression ← snapshot；intent / models ← approach；events ← social / covert / threads；approach / combat / social / covert ← stakes；events / snapshot ← reputation；events / snapshot / approach / stakes / reputation / threads ← rules ← aggregates（另依赖 stakes / threads）；combat 与 progression 都是纯函数，聚合根、快照与规则共用同一套折算；clocks ← events ← resolution（另依赖 combat / social / covert / stakes / snapshot）← rules ← aggregates
- 世界心跳：intent ← commands ← rules（门面 command）；ambient 自立；ambient / commands ← events / snapshot / aggregates；heartbeat 依赖 ambient / commands / events / models / combat / outcomes / snapshot（PlayerState 只在类型标注里），自身不被领域里任何模块依赖——由 application/world_clock 调用
- 空间属性图：commands / intent / lore ← geography（WorldBlueprint 只在类型标注里）← models（运行期导入：Passage / Sight 是蓝图字段，geography_errors 并进蓝图闸门）/ snapshot（ExitView 的方位、交通方式、认知）/ heartbeat（Atlas 读 ways）；迷雾的口径全在 geography 与 snapshot（shown_name / names / handle / exit_names），rules 的移动与问路只认它们
- 分层 NPC 生态：agenda 只有名词、自立，events / aggregates 由此导入；npc 依赖 agenda / heartbeat / events / ambient / commands / models / resolution（PlayerState 只在类型标注里），自身不被领域里任何模块依赖——application/world_clock 每回合调 march，application/npc_agent 调规划闸门与裁决层
